# Task Manager - Менеджер задач

## Автор
**Иван Иванов** (пример)

## Краткое описание
Консольное приложение для управления задачами с использованием:
- **MVC архитектуры** (Model-View-Controller)
- **Очереди** для задач по приоритету
- **Стека** для отмены/повтора действий (Undo/Redo)
- **JSON** для сохранения данных
- **ООП** (инкапсуляция, наследование, полиморфизм)

## Возможности
- ✅ Добавление, редактирование, удаление задач
- ✅ Фильтрация по статусу (To Do, In Progress, Done) и приоритету (Low, Medium, High)
- ✅ Очередь приоритетов для оптимального планирования
- ✅ Отмена и повтор последних действий (Undo/Redo)
- ✅ Автоматическое сохранение в JSON
- ✅ Валидация всех вводимых данных
